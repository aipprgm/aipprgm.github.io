# AIP Applicant Hub

A community website for Atlantic Immigration Program (AIP) applicants, published at
https://aipprgm.github.io.

## Updating the site

- **Add a PDF:** upload it to the `files/` folder (on GitHub: open `files`, then
  Add file → Upload files). It appears in the "PDFs and downloads" section automatically.
- **Add or change a link card:** edit the `RESOURCES` list at the top of `app.js`.
  Google Sheets and Docs only need their ID (the long part of the link after `/d/`).
- **Change page text:** edit `index.html`.

Google Sheets and Docs must be shared as "Anyone with the link can view" for the
preview and download buttons to work.

This is a community resource, not legal advice, and not affiliated with IRCC.
